# 地图 UI 接缝修复计划

日期：2026-10-12

## 目标

保留停云客栈现有画风和房间布局，改善地图建筑接缝、重复纹理及交互边框造成的分块感。人物使用已恢复的专属头像。

## 范围与约束

- 保留 768×512 逻辑画布、房间矩形、路线端点、人物基线和移动规则。
- 原始底图保留，新底图采用独立版本文件，便于比较和回退。
- 有底图时移除房间卡片式缩放、圆角、边框及矩形呼吸光；无底图的回退地图保留原有表现。
- 当前房间、可达、选中、键盘焦点用标签及门口反馈表达。
- 底图美术使用 imagegen 编辑；输出必须检查尺寸、房间位置和建筑衔接后才能接入。

## 实施顺序

1. 完成本文，再修改代码及素材。
2. 修改地图 CSS：固定交互区域，不缩放；状态反馈集中于标签和现有门口标记；清除装饰区域虚线框。
3. 编辑一层底图：马厩/后院门槛、后院/厨房边柱、房间行之间结构分隔、正门周围地面与大堂过渡。
4. 编辑二层底图：共享隔墙、统一地板线、回廊与挑空区连续梁柱，减轻模块重复感。
5. 检查生成图；合格后更新地图绑定并更新静态资源版本。
6. 运行地图绑定测试和现有浏览器烟测；检查桌面、窄屏、两层及交互状态截图。
7. 更新本文执行记录，注明完成内容、验证结果及尚存限制。

## 验收标准

- 默认状态没有覆盖整间房的圆角矩形边框；悬停、选中不会使交互区域缩小。
- 当前、可达、选中和键盘焦点清晰可辨；门口及移动路径仍与原坐标对应。
- 室内外接缝有门槛、台阶或明确结构收口；相邻素材不出现明显双柱和截断梁。
- 正门所在底部区域具有环境衔接；二层回廊不出现突兀的模块边缘。
- 头像可加载；楼层切换、路线、移动和无底图回退正常。
- 新素材与旧素材分别保留；无法满足坐标约束的生成结果不接入。

- 修订：门框改为无屋檐、无周围墙面、暗色门洞的透明素材，采用 44×74 的等比完整显示；马厩/后院与正门/大堂复用底图建筑，不重复贴门；保留端点与可达提示。
