# 停云客栈地图重构与生成 Skill 设计

## 调研结论

- 当前地图由 12 个地点和 13 条双向连接组成；`connections` 是移动规则真源，旧 `layout` 仅用于 6×4 CSS Grid 排版。
- 旧 UI 用房间卡片和姓名徽章表达位置，移动是跨卡片直线动画，缺少门、走廊、楼层入口与可达反馈。
- 新版采用 **DOM 房间 + SVG 路径 + DOM 角色**。它保留文本可访问性和现有 Flask 静态资源方式，同时支持可编辑路线与沿路径运动。
- 玩家视图继续只显示自己和同室可见人物；观察者与导演可显示全员。公开地图拓扑不能携带角色隐私。
- 旧版 Pixi/Tiled 地图为 32px、400×200 格的超大画布，单张底图约 55MB，不作为新互动地图依赖。

## 地图规格

每层使用 12×8 逻辑网格，格宽 64px，SVG `viewBox` 为 768×512。房间墙体内缩 6px，标题区 36px；角色占位约 40×52px，按 48×60px 的节奏排列。

## 连接与交互

- 13 条 `routes` 必须与规则连接无遗漏、无额外边：普通门/走廊 11 条，马厩至正门为室外有顶通道，木梯至二层回廊为跨层路线。
- 所有连接使用低亮度 SVG 线；玩家当前位置可直达路线显示为金色，悬停房间会同时强调相邻房间和路线。
- 点击可达房间只选择现有“移动”目的地，不自动提交；不可达房间不响应移动选择。
- 当前楼层由标签切换并显示可见人数。跨层移动先进入楼梯、淡出、切层，再从回廊入口出现。
- 小人使用共享人物立绘；缺图时显示姓名首字。角色按稳定 ID 排序分配房间站位，刷新时不会随机跳位。
- `prefers-reduced-motion` 下直接更新位置。找不到视觉路线时使用直线回退，不影响事件队列。

## 数据接口

`map_binding.json` 包含：

- `schema_version`、`projection`、`grid`、`floors`
- `rooms`：地点、楼层、矩形、主题和站位网格
- `routes`：规则端点、路线类型和逐层折线路点
- `decorations`、`asset_manifest`

场景装载器验证整数坐标、边界、重叠、地点全集、容量与规则图一致性。玩家、观察者和导演状态均增加公开 `map` 字段；它不包含人物状态或剧本秘密。

## 可复制主 Prompt

```text
使用 $agents-town-map-builder 为给定 Agents Town 世界设计并准备可生产的互动地图。先完成图结构、map_binding、完整资产清单、逐资产提示词、精确像素尺寸和验证，展示生产计划后停止，等待我批准。只有明确批准后才可调用 ImageGen。

批准后先生成风格锚点、代表房间、主楼梯下段及与其匹配的上层梯口；经检查通过后再生成其余房间。所有生成图必须经 prepare_map_assets.py 按“地块格数 × tile_size × render_scale”进行 LANCZOS 等比缩放和自动拼装：底图用 cover-crop，透明楼梯/装饰用 contain 与固定锚点。不得手工拉伸，也不得交付缺失楼梯、尺寸错误、透明度错误或未经复检的拼接图。
```

完整可复制版本见 `skills/agents-town-map-builder/references/prompt-template.md`。

## 美术生产升级

- 首版生产清单采用 `render_scale=2`，每层最终底图为 1536×1024。
- 清单共 18 项：两层底材、12 个房间、二层挑空区、地窖石阶、主楼梯下段和上层梯口。
- 每个房间底图使用独立尺寸；主楼梯上下层资产共享结构参考，避免踏步宽度、栏杆和光向不一致。
- `report_asset_plan.py` 从网格直接输出尺寸表，避免手写像素漂移。
- `prepare_map_assets.py` 负责等比 resize、透明裁切、锚点放置、按 z 序拼装和构建报告；超过 1.25 倍的放大直接失败并要求重生成。
- 提示词与候选策略保存在 `art/v001/prompt-ledger.json`，当前状态为 `awaiting_user_approval`，尚未生成任何底图。

详细风格、楼梯提示词、单变量修图流程与负面约束见 Skill 的 `visual-style.md` 和 `image-production.md`。

## 验收

- Schema：12 个房间、13 条唯一无向路线、坐标合法、无重叠、容量充足。
- UI：房间、门路、楼层和角色清晰；可达状态与动作下拉框同步。
- 动画：同层、室外、跨层、连续事件、直线回退与减少动态效果正确。
- 隐私：玩家只看到自身和现场人物；观察者、导演显示六人。
- 视口：1600×1100、1280×800、390×844 无裁切和覆盖。
- 回归：玩家、观察者、导演、规则引擎、旧地图回退与持久化测试继续通过。
