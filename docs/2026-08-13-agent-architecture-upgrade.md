# Agent 提示词与服务架构升级（2026-08-13）

本轮完成三个相互配合的改造：提示词模板化与版本化、上下文超限保护，以及 `GameSession` 的渐进式服务拆分。

## 提示词版本与审计

互动 Agent 的行动、玩家对话和终局投票分别使用独立模板，统一由 `PromptCatalog` 注册。每个模板具有稳定的 `prompt_id`、语义化版本和输出 Schema 版本。

每次模型调用的 JSONL 追踪现在额外记录：

- `prompt_id`、`prompt_version`、`schema_version`；
- 原始结构化上下文的 SHA-256 哈希；
- 提示词估算 token；
- 是否触发上下文压缩、压缩前后估算与摘要内容。

相同审计摘要也会写入游戏的 `model_usage`，便于复盘某个行为究竟由哪个模板版本产生。

## 上下文超限保护

默认上下文窗口由 `GA_INTERACTIVE_CONTEXT_WINDOW_TOKENS` 控制，未设置时按 32768 token 规划，并为模型输出与安全边界预留空间。

预算足够时上下文保持不变。只有预计超限时才依次执行：

1. 将较旧 Belief 和事件压缩为结构化摘要，保留近期原文；
2. 缩短过长的非核心描述字段；
3. 继续裁剪已知会增长的历史列表。

角色身份、当前观察、规则、秘密和输出协议不在常规历史裁剪范围内。所有压缩均为确定性操作，不额外调用模型；摘要或预算不足不能阻断整轮游戏。

## 服务拆分

从原有 `GameSession` 中提取了两个服务：

- `CognitionService`：计划闭环、结构化策略同步、事件写入记忆、印证关系与待核实问题；
- `StateProjectionService`：玩家公开状态、观察者状态和主持台私有状态投影。

`GameSession` 保留原方法作为兼容委托，既不改变现有 API，也不影响旧存档加载。后续可用相同方式继续提取对话、承诺、投票和计分服务。

## 验证

- Python 完整回归：121 项测试与 3 个子测试通过；
- 信息隔离、规划闭环、玩家模式和主持台私有投影均有定向覆盖；
